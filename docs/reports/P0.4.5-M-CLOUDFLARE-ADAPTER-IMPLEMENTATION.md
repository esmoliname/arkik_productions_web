## 2. Corrección de detección Cloudflare

`wrangler.jsonc` incluye `vars.DEPLOY_PLATFORM = "cloudflare-pages"` (configuración no sensible). Preview/Production se distinguen por `APP_ENV`.

### Flujo verificado
`context.env` → `env-context.runWithEnv` → `cf-adapter.invokeHandler` → `config.readEnv` → autenticación → cookie. No se asigna `context.env` a `process.env` global. No se muta configuración global compartida.

### Fail-closed
- `config.sessionSecret` lanza 503 si falta y no es dev local explícito.
- `assertSecureCookieAllowed` solo bloquea staging fuera de Vercel/Cloudflare sin `SECURE_COOKIES`. En Cloudflare, `isCloud` verdadero ⇒ no bloquea y Secure siempre activo.
- `SECURE_COOKIES=false` no debilita la protección en entorno cloud (Secure sigue activo por `isCloud`).

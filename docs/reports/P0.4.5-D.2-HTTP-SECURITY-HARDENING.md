## 2. CSP policy (Report-Only)

Header: `Content-Security-Policy-Report-Only` (not enforcing; violations are reported to
browser console / any configured report endpoint). Applied to `/(.*)`.

Policy:
```
default-src 'self';
script-src 'self' 'unsafe-inline' 'unsafe-eval' https://cdn.tailwindcss.com https://cdnjs.cloudflare.com https://cdn.jsdelivr.net;
style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
img-src 'self' data: https:;
font-src 'self' https://fonts.gstatic.com data:;
connect-src 'self' https://api.emailjs.com https://cdn.jsdelivr.net;
frame-src 'none';
object-src 'none';
base-uri 'self';
frame-ancestors 'none';
form-action 'self'
```

Inventory of directives:
- script-src: Tailwind Play CDN (runtime compiler), versioned CDNs, inline config block.
- style-src: Google Fonts, inline Tailwind classes.
- img-src: self, data URIs, any HTTPS (twitter card image, booking assets).
- font-src: Google Fonts (gstatic), self, data.
- connect-src: same-origin API, EmailJS API, jsdelivr (docx/emailjs fetches).
- frame-src/object-src: none (no embedded frames/objects).
- base-uri/frame-ancestors/form-action: self/none.

## 3. Justifications for unsafe-* (Report-Only only)

- `'unsafe-inline'` (script-src): index.html contains an inline Tailwind config block
  (`tailwind.config = {...}`). Migrating to a nonce/hash is a follow-up before enforcement.
- `'unsafe-eval'` (script-src): Tailwind Play CDN compiles utility classes at runtime
  using `eval`. Removing it requires switching to a pre-built Tailwind CSS file.
- `'unsafe-inline'` (style-src): Tailwind injects inline styles.

These are acceptable in Report-Only mode and are documented as blockers for enforcement.

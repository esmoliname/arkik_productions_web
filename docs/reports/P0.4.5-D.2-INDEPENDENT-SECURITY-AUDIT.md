## 2. Findings

### CRITICAL
None.

### HIGH
None introduced by D.2. Pre-existing H-01 (Vercel billing) and H-02 (uncommitted
working tree) remain external/conditional.

### MEDIUM
- **D2-M1 (residual):** Tailwind Play CDN (`cdn.tailwindcss.com`) still loaded without
  SRI and requires `'unsafe-eval'` in CSP. Mitigation: CSP is Report-Only; documented
  follow-up to switch to pre-built Tailwind CSS. Severity MEDIUM (unchanged from H-04).
- **D2-M2:** CSP still permits `'unsafe-inline'` for scripts/styles (required by inline
  Tailwind config). Acceptable in Report-Only; must be removed before enforcement.

### LOW
- **D2-L1:** `SECURE_COOKIES` flag is opt-in and undocumented in `.env.example`. Consider
  adding a commented entry to `.env.example` in a follow-up (no secret value).
- **D2-L2:** Migration 007 uses column-level UPDATE grant; verify Neon PG version supports
  it in staging before applying.
- **D2-L3:** `db/provisioning/README.md` still references non-existent `002_grants_extra.sql`
  (pre-existing, carried over).

### INFORMATIONAL
- D2-I1: scrypt cost (2^14) below OWASP 2^17 floor; deferred to next auth phase with
  versioned-hash rehash strategy. No regression.
- D2-I2: MFA/passkeys not implemented; proposal delivered in authentication report.
